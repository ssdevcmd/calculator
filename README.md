# 🧩 Calculator

A clean, responsive, and fully functional calculator built using HTML5, CSS3, and Vanilla JavaScript. Designed with a modern dark theme and robust state management to handle basic arithmetic operations smoothly.

🔗 **Live Demo:** [View Calculator Live](https://magenta-marzipan-dca933.netlify.app/)

---

## ✨ Features

- **Standard Arithmetic Operations:** Supports addition, subtraction, multiplication, and division.
- **Decimal Precision:** Handles decimal point inputs cleanly without breaking formatting.
- **Dynamic Display:** Real-time screen updates for user inputs and calculation results.
- **State Management:** Robust operand tracking and operator handling to mimic physical calculator behavior.
- **Responsive Design:** Clean CSS Grid layout styled for a sleek, modern user experience.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup for calculator structure and layout.
- **CSS3:** Flexbox & CSS Grid for clean keypad alignment and modern dark UI styling.
- **JavaScript (ES6+):** DOM manipulation, event delegation, and core arithmetic logic.
